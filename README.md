\# Lunar Lander 2D



A 2D Lunar Lander-style game built in Unity 6 (6000.0.44f1) with C#.

Land your spaceship safely on the pad. Land too fast or at a steep angle and you crash.



\## Features

\- Physics-based thrust and rotation

\- Landing detection (speed and angle checks)

\- Landing pads with score multipliers

\- Fuel and coin pickups

\- Multiple levels, menus, and sound



\## Built with

\- Unity 6 (Universal 2D)

\- C#

\- Cinemachine, Input System, SpriteShape
